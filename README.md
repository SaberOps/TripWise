# TRIPWISE – Your Smart Travel Companion

## Project Description

TRIPWISE is a web application designed to help users organize and manage their travels.

The application allows users to discover destinations, plan trips, manage favorites, and track their travel budgets.

This project is developed as part of the Angular Development module.

## Project Objectives

- Develop a complete web application using Angular.
- Build a REST API connected to a database.
- Document the REST API using Swagger UI.
- Implement CRUD operations for at least two entities.
- Use Angular services, dependency injection, Signals, routing, and reactive forms.
- Write unit tests.
- Deploy the application using Docker and Docker Compose.

## Installation and Execution

The complete application will be launched using:

```bash
docker compose up --build
```

The application URLs will be:

- Frontend: http://localhost:4200
- Backend API: http://localhost:5000/api
- Swagger UI: http://localhost:5000/swagger

These URLs will become available after the frontend, backend, and Docker configurations are implemented.
